## 决策记录

### R1 — chat-completions 稀疏索引丢弃（openai）
`partners/openai/chat_completions_stream.go` finalToolCallChunk 按 `for i := 0; i < len(s.toolCalls); i++` 遍历 map，稀疏索引（最高索引下方有洞）的 call 被丢。Python `chat_model_stream.py` `_merge_chunk_into_store` 按 `dict[int]` 合并、`sorted(store)` 终结——全部保留。修复：按 Python 语义迭代实际存在的索引（排序后逐个），保留全部 calls；更新锁定测试 `TestChatCompletionsStreamSparseToolCallIndex`（从"锁定丢弃"翻转为"锁定保留"）；撤掉对应 DIVERGENCES 条目。

### R2 — anthropic 残留四项（同文件链，一任务串行做）
1. **hoist 路径 unrecognized-block 收窄**：Python `_format_system_content`（chat_models.py ~635-642）在所有调用点无条件 drop 非文本/非 tool-change system block + warning；Go 目前仅 in-place 路径收窄（`narrowUnknown=true`），hoist 路径透传。修复：hoist 路径同样收窄 + 对齐 Python warning 文案；更新 DIVERGENCES。
2. **新模型 thinking 校验**：Python chat_models.py ~1829-1849 — opus-5/fable/sonnet-5-5 拒绝 `thinking={"type":"enabled"}`（全 effort 级别）；fable/sonnet-5-5 拒绝 `{"type":"disabled"}`；报错文案/建议 remedy 对齐。模型集合从 profile 数据判定还是硬编码——按 Python 实现方式定。
3. **thinking-display / user-profiles betas 自动追加**：chat_models.py ~2130-2138、~2163-2170 的触发条件（payload 含何种结构时追加 `thinking-display-updates-2026-08-18` / `user-profiles-2026-03-24`）——读源码确定触发条件后移植到既有 `requiredBetaHeaders` 机制（含 supersede/append-if-absent 规则与 beta 端点路由）。
4. **构造器 output_config dict**：Python 构造器接受 `output_config` dict（`task_budget`、`format`），merge 顺序在 effort-derived keys 之前（chat_models.py ~1495 + payload build）。Go 加 `WithOutputConfig(map[string]any)`（或等价选项），emission 顺序对齐；校验与 effort 的交互按 Python。

### R3 — langgraph checkpoint 残留（同文件链）
1. **pause repair 查抑制集**：`deltaRepairSnapshots()` 构建 repair payload 时不查本次 pause save 的 suppression 集，会把被抑制 channel 的 blob materialize 到 repair checkpoint（stranded writes）。修复：repair payload 对被抑制 channel 不带 blob（与 pause save 的存储形状一致——blob-free + sentinel）。exit 分支 `putPauseCheckpointExit` 的 repair 同理。
2. **exit-mode putPauseWrites 失败不 repairPut**：`checkpoint_sink.go` DurabilityExit 分支 PutWrites 失败只 poison 不 repair——补 repairPut（与 sibling 路径一致）。
3. **interrupt_after 暂停欠持久化 below-cadence delta 写**：Go interrupt_after early return 跳过 per-task putWrites（graph.go ~2000 邻域），暂停 checkpoint 下已 apply 的 sibling delta 写未持久化，读/resume 短读。读 Python `_loop.py` 的 interrupt_after 时序（superstep commit 的 writes 持久化先于/伴随 pause 保存），对齐 Go 时序。
4. **nil-ChannelValues 专用单测**（test-only）：snapshotFromTuple 的 nil decode guard。
