# Parity Wave 4 Residuals（v0.12.1）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 清偿 wave4 审计记入 DIVERGENCES 的全部可移植残留（openai 稀疏索引、anthropic 四项、langgraph checkpoint 三项 + 一个测试），加 CI gofmt 门禁，发布 v0.12.1。

**Architecture:** 四个任务按文件域切分（partners/openai 独立；anthropic 同文件链串行四项；langgraph checkpoint 同文件链串行四项；docs/CI 收口），全部对照 Python 参考（spec R1–R4 为决策记录）。

**Tech Stack:** Go 1.26+；无新外部依赖。

**Spec:** `docs/superpowers/specs/2026-11-02-v0.12.1-residuals-design.md`

## Global Constraints

- Python 参考路径与门禁与 wave4 相同（langchain @ langchain-core==1.7.3、langgraph @ 1.2.19；build/vet/test -race、触及嵌套模块才 make test-*、lint 零 issue、触及追踪包 make coverage）。
- TDD 强制；conventional commits 引上游 PR/commit；不破坏公共 API（additive 可以）；修复后撤/改对应 DIVERGENCES 条目随代码 commit。

## Review Focus

1. 稀疏索引修复不得破坏稠密索引快路径（现有 golden 不回归）。
2. anthropic betas 追加的触发条件必须逐条对照 Python（不是猜测的形状）。
3. checkpoint repair 的存储形状必须与被 repair 的 pause save 一致（blob-free + sentinel），否则引入新 stranding。
4. interrupt_after 时序调整不得改变 sync/async/exit 三模式的既有历史一致性断言。
