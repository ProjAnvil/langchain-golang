# LangChain examples

Examples whose primary surface is LangChain core, `langchain/agents`,
middleware, retrievers, toolkits, or partner integrations. LangGraph may be an
internal dependency, but it is not the feature under demonstration.

Each subdirectory is an independent Go module.

| Example | Focus |
| --- | --- |
| `advanced-retrievers` | Ensemble + multi-query retrieval |
| `gemini-agent` | Gemini tool-calling agent |
| `mcp-tools` | MCP tools through an agent |
| `middleware-suite` | TodoList, summarization, and PII middleware |
| `quickstart` | Smallest `CreateAgent` model/tool loop |
| `rag-fullchain` | Load → split → embed → retrieve → rerank → answer |
| `sql-agent` | Read-only SQL toolkit agent |
| `streaming` | `Agent.StreamEvents` |

See the [examples index](../README.md) for validation.
